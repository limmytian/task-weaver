# 交付物读取协议摘要

规范以英文文档为准。读取请求只携带已注册输出 ID 和用途；服务端重新检查项目权限并解析生产节点与不可变指纹，浏览器不能提供文件路径或远程地址。节点请求绑定 daemon、节点、输出、随机数和过期时间，顺序与终态需要防重放；取消、权限撤销、断线或指纹不符均终止传输。

节点必须在受限目录中安全打开普通文件，并在声称验证成功前核对完整大小和 SHA-256。初始上限为完整文件 100 MiB、请求 30 秒、每节点并发 2；预览与 Git diff 另有更小的限制。提升到附件时绑定不可变文件版本，不能删除本地文件或自动通过验收。离线、丢失、变化、退役、不支持及超限分别报告。协议契约不代表节点传输或界面已经实现。
