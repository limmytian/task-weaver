# 交付物读取协议摘要

规范以英文文档为准。读取请求只携带已注册输出 ID 和用途；服务端重新检查项目权限并解析生产节点与不可变指纹，浏览器不能提供文件路径或远程地址。节点请求绑定 daemon、节点、输出、随机数和过期时间，顺序与终态需要防重放；取消、权限撤销、断线或指纹不符均终止传输。

节点必须在受限目录中安全打开普通文件，并在声称验证成功前核对完整大小和 SHA-256。初始上限为完整文件 100 MiB、请求 30 秒、每节点并发 2；预览与 Git diff 另有更小的限制。节点读取目前需要在单个 API 实例和 Linux 生产节点上显式启用，并且旧输出缺少密钥绑定时不可读取。预览会先从节点传输并校验完整文件，再在浏览器中限制采样；界面会告知这一成本。

有写权限的成员可以将验证后的内容保存为不可变附件；重复提升复用同一版本，节点离线后仍可读取。安全文件类型可以预览，HTML、SVG 和未知类型只供下载。GitHub 证据通过受信任的仓库连接固定提交，逐文件读取前后重新检查权限；其他提供方和浏览器验收仍待完成。提升不会删除本地文件或自动通过验收。离线、丢失、变化、退役、不支持及超限分别报告。
