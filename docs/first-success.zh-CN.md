# 首次成功协作

从“Projects”创建或打开项目，进入“First success guide”。也可以显式选择“Try an isolated sample”，建立独立的示例项目。打开引导不会执行任务，尚未接入 Agent 也能规划和手动完成示例。

1. 写清一个目标和验收标准。
2. 准备计划草稿，审阅任务及依赖，校验已保存版本后显式应用。新需求仍为草案。
3. 检查需求范围后显式批准，草案不能执行。
4. 可选：复用现有受限凭据、仓库就绪检查和 Daemons 执行器诊断。未知检查不视为就绪；可跳过 Agent 接入。
5. 通过现有任务操作产出结果。示例要求在任务中添加一句结果评论，标记任务完成，并复制评论 ID。
6. 在需求工作流中登记评论交付，检查内容，填写理由后完成交付和人工验收。任务完成本身不代表结果已审阅。

引导跟随项目中最近更新且未取消的需求，从服务端真实业务记录恢复进度；交付需匹配当前计划和工作流版本。浏览器只保存按用户、项目隔离的隐藏及跳过偏好，不保存密钥或完成标记。隐藏后可以重新显示。

示例项目名称带有“[Sample]”。创建示例项目、生成计划、应用计划和批准需求均为显式操作。“Archive this sample project”仅归档该示例项目，保留计划、需求、任务和证据，其他项目不受影响；可在项目设置恢复。未应用的计划也可直接丢弃。

已有用户会看到现有业务状态，不会被重置。只读或失权时不会推断成功。本地人工样例检查与真实 Agent 执行不同；正式环境的仓库、执行器及实际交付仍须单独验收。
