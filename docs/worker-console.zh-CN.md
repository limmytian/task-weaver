# 按需查看 worker 控制台

英文规范见 [worker-console.md](worker-console.md)。本页为独立中文摘要。

在 daemon 页面打开当前执行 worker 的控制台，获取近期输出快照；选择 Follow live 后才继续请求后续输出。关闭、停止或隐藏页面会取消观察需求。暂停滚动只影响显示，不暂停任务。支持 stdout/stderr 过滤和复制当前显示文本。没有输出不代表进程卡死；控制台文本不证明任务完成或能力采用。

daemon 复用已有执行控制轮询，经认证 HTTP 回传有界批次。没有观察需求时不上传正文，不新增本机监听端口或常驻输出连接。正文只保存在短时有界内存，不进入数据库、活动事件、结构化日志、遥测或 PostgreSQL NOTIFY。代理与追踪系统也应排除这些路由的正文记录。

单 API 进程使用默认 local 路由。多进程需要为每个进程配置唯一的 TW_CONSOLE_NODE_ID，并配置相同的 TW_CONSOLE_PEERS 可信 HTTPS 节点地址映射，最多八个节点；本机夹具可使用回环 HTTP。映射必须指向具体进程，不能指向负载均衡入口。缺少路由、节点不可用和重启丢失内存会明确失败，不静默重放或恢复旧会话。不要在源码中提交私有地址或凭据。

观察者必须是当前具备该需求 resource.read 和 audit.read 权限的人类身份。会话绑定具体凭据、任务、run、worker 索引、租约 generation 和采集进程 UUID；每次读取、续期、下发和响应都会重新校验。撤权后被删除的会话不能因重新授权而复活，必须重新打开。已交付的字节无法召回。旧节点、重规划与索引复用不能把旧控制台接到新进程。

当前支持 executor worker。Codex JSONL 只提取命令输出和最终助手文本，省略推理、提示词、参数和未知事件；Codex 可能已将嵌套命令的两个流合并到模型进程 stdout。模型进程 stderr 单独展示。其他 provider 的两个流及 reviewer/merger 明确显示不支持，不猜测解析。没有 stdin 注入、远程终端或任意命令/文件访问。

主要上限：daemon 每个当前进程 256 KiB／1024 帧／60 秒；单帧 4096 UTF-8 字节、单批 32 KiB；API 每进程 128 个会话、每凭据/run 四个观察者；快照初始超时 15 秒，跟随租约 10 秒、会话绝对上限 15 分钟；浏览器 256 KiB／1024 帧。慢消费者会看到截断或缺口，不会阻塞 worker。退出、重启、未采集与过期历史不能恢复。

处理流式 UTF-8、跨 chunk 已知秘密掩码、终端控制符和安全文本渲染。已知秘密掩码不保证发现任意秘密。测试与真实模型验收范围、清理和未知成本须按各自证据报告；不把源码检查当作所有客户端认证。
