# 计划暂存摘要

英文文档为规范版本。项目成员可以保存计划草稿，查看依赖、任务和执行切片，校验并审阅影响后再明确应用。暂存本身不创建任务；新需求默认 draft，新任务默认 todo，审批是单独操作。引用现有对象不会直接修改其字段，但给现有需求添加工作可能影响执行，仍受租约和计划变更保护。

项目页面可以创建或重开草稿；需求详情页可以创建预先引用当前需求的草稿。编辑器显示依赖图和切片泳道，并提供可用键盘操作的列表编辑。先保存，再校验和审阅影响，最后由有权限的成员明确应用。Ti Assistant 和 MCP 的暂存入口返回可打开的草稿，而不会直接执行计划。

保存使用版本号防止覆盖并发编辑；校验后草稿或项目计划变化时必须重新校验。应用使用操作 UUID 防重复，并提供持久回执。草稿创建后 30 天过期；新建草稿时会顺带清理同项目最多 100 条过期草稿或已丢弃记录；长期不新建草稿的项目需要管理员安排清理。
