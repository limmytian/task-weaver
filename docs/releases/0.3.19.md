# Task Weaver 0.3.19

[简体中文](0.3.19.zh-CN.md).

## Decisions that need attention

The new Needs attention entry groups visible recovery decisions, execution and
delivery failures, work awaiting review and blocking dependencies. Queries use
current permissions and bounded pagination. Counts describe the current page;
unavailable observations remain unknown. Items link to existing guarded review,
recovery and dependency actions. Opening the workbench never approves or retries
work. See [Needs attention](../attention-workbench.md).

## First successful collaboration

A project guide connects existing planning, explicit approval, optional agent
setup and evidence review. Progress derives from server records and resumes after
refresh. Sample content requires explicit selection, stays in a marked isolated
project and can be archived without affecting other projects. Browser storage
contains only presentation preferences. See the [first-success guide](../first-success.md).

## Maintenance and compatibility

The daemon delivery attempt and operational Web sections are separated into
cohesive typed modules while retaining lease, cancellation, recovery, cleanup and
permission behavior. No browser automation framework, new state library or
collaboration-effectiveness metrics are introduced.

There are no new database migrations beyond 0.3.18. Existing public 0.3.18 tags,
images and packages remain immutable. Back up retained data and follow the
[upgrade guide](../ce-upgrades.md). BusyBox CVE-2025-60876 package-version matches
remain disclosed; successful control-character checks do not establish that the
vulnerability is eliminated.

Validation includes existing workspace checks, isolated PostgreSQL feature
regressions and scoped manual local-page checks. Operator fixtures are distinct
from autonomous execution. Real executor/fleet behavior and active-worker console
end-to-end acceptance were not established by the local fixtures.
