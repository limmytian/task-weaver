# Task Weaver 0.3.19

[English](0.3.19.md).

## 需要处理的决策

新增 Needs attention 入口，汇总当前权限下可见的恢复决策、执行与交付失败、待审阅结果和依赖阻塞。查询及分页有界，条数仅代表当前页，不可用状态保持未知。操作跳转到现有受保护的审阅、恢复和依赖入口；打开工作台不会自动批准或重试。

## 首次成功体验

项目引导串联现有计划、显式批准、可选 Agent 接入和证据审阅。进度依据服务端真实记录，刷新后可恢复。示例内容须显式选择，位于独立标记项目内，可归档清理且不影响其他项目。浏览器只保存界面偏好。详见[首次成功指南](../first-success.zh-CN.md)。

## 维护性与兼容性

daemon 交付执行及运维页面拆为职责明确的类型化模块，保持租约、取消、恢复、清理和权限行为。未引入浏览器自动回归框架、新状态库或协作成效统计。

相较 0.3.18 没有新增数据库迁移。既有公开标签、镜像和包保持不可变。升级前备份保留数据并遵循[升级指南](../ce-upgrades.md)。BusyBox CVE-2025-60876 包版本匹配仍予披露；控制字符检查通过不代表漏洞已消除。

验证覆盖现有工作区检查、隔离 PostgreSQL 回归和限定人工页面检查。人工样例不同于自主执行；本地样例未证明真实执行器、集群行为或活跃 Worker 控制台端到端验收。
