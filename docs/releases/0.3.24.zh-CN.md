# Task Weaver 0.3.24

[English](0.3.24.md).

## 可靠性与 Worker 恢复

Worker 异常进入 Needs attention，保留尝试证据，并提供受保护的恢复操作。显式重试决定保留租约隔离，拒绝过期结果写入。人工交付同步等待未结束的 Worker 尝试。

## 交付与用量

需求页面展示交付效果、Worker 审阅、额外尝试和恢复决定。范围化用量报告区分完整、部分和未知计数，单独展示缓存计数。

## 升级与验证

此补丁沿用 0.3.23 的数据库迁移集合。升级前备份数据库和附件，并遵循[升级指南](../ce-upgrades.md)。

验证涵盖鉴权 PostgreSQL、历史升级与恢复、生产构建网页恢复、真实 Worker 竞争以及私有 GitHub 验收和版本集成。历史 OOM 触发原因仍待确认，限定负载检查通过。可选的真实 Ti/gateway 验证仍未覆盖。
