# Task Weaver 0.3.18

[English](0.3.18.md).

## Node 运行时安全

将 Node 运行时及构建验证基线更新至 24.22.2，包含 24.22.1 对 CVE-2026-111497、CVE-2026-105482、CVE-2026-106069 和 CVE-2026-105483 的安全修复。应用镜像从摘要固定的官方 Node 镜像复制经核验的运行时和头文件，同时保留已审阅的 Alpine 包基线。同步更新源码校验和、Node 原始许可证文本及对应源码声明包。

0.3.17 源码候选已创建标签，但新镜像扫描发现其中 Node 24.21.0 的漏洞，因此未放行二进制发布。其公开 Git 标签保持不可变。此补丁承接 [0.3.17 准备说明](0.3.17.zh-CN.md)中的 CLI 分发、审阅证据及版本／latest 镜像标签改进。

## 发布与升级

两个应用架构均须通过运行时、源码、部署与漏洞门禁后才能发布。BusyBox CVE-2025-60876 的包版本匹配继续披露，与 Node 修复分开记录。原始控制字符回归检查通过不代表漏洞清零。

相比 0.3.16 未增加数据库迁移。请备份保留数据并遵循[升级指南](../ce-upgrades.md)。已公开版本及标签保持不可变。
