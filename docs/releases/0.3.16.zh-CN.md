# Task Weaver 0.3.16

[English](0.3.16.md).

## 依赖与渲染安全

升级存在已知漏洞的生产与开发依赖，包含 Hono、Mermaid、KaTeX、IP 地址和 URI
解析相关依赖。Mermaid 预览启用严格模式，并在插入页面前经过 DOMPurify 清理。
正常图表标签和数学公式仍受支持；嵌入媒体和脚本链接会被移除。
构建直接使用保留在源码中的 MIT 许可 shadcn 样式，不再安装可选组件生成器及其依赖。

固定摘要的 Alpine 运行环境安装 musl 和 musl-utils `1.2.5-r24`。
BusyBox 的 `CVE-2025-60876` 记录仍然存在：配置的 Alpine 仓库当前没有修复包。
这些记录被保留，未通过忽略规则隐藏。漏洞结果以验证时使用的公告数据库为准。

## 公开产物隐私

源码归档、npm 暂存包与最终发布目录会拒绝本地配置、私钥、数据库备份、个人主目录路径、
符号链接及可识别的凭证格式。检查覆盖编译后的包文件，错误只输出位置和类别，不输出匹配值。
扫描报告会清理主机个人路径；Git 和 Docker 排除规则也覆盖操作员凭证目录及备份。

这些检查需要配合人工审阅，无法识别所有私有域名或任意敏感文档。已有公开版本保持不可变。

## 升级

相较 0.3.15 不增加数据库迁移或数据改写。部署前继续执行标准候选验证与不可变发布流程。
