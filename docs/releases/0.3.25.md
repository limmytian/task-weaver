# Task Weaver 0.3.25

[简体中文](0.3.25.zh-CN.md).

## Targeted task claims

Workers can claim a specific task by id through the claim API instead of accepting whatever the scheduler assigns. Thin claims return a private attempt token and fenced lease, honor an optional requested Codex model, and use the bounded thin lease duration. The `tw task claim` CLI command claims the specified task, and `tw task release` applies to legacy claims while thin attempts use the fenced worker release API.

## Worker identification

The project Workers tab is identified with a dedicated icon, and the agent skill documents the targeted claim flow for thin tasks.

## Node runtime security

Update the Node runtime to 24.22.3, which includes the security fixes for CVE-2026-126051, CVE-2026-123863, CVE-2026-123864, CVE-2026-123865, CVE-2026-123866, CVE-2026-123872 and CVE-2026-123874. Fresh candidate scans detected the seven high-severity findings in the previously shipped Node 24.22.2 runtime before publication, and the first 0.3.25 candidate was withheld and repaired before any artifact was published. The application images copy the verified runtime and headers from the digest-pinned official Node image while retaining the reviewed Alpine package baseline. Source checksums, original Node license texts and the corresponding-source notice bundle are updated together.
