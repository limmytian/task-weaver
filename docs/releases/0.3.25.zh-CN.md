# Task Weaver 0.3.25

[English](0.3.25.md).

## 定向任务认领

Worker 可以通过认领 API 按任务 ID 认领指定任务，而不必接受调度器分配的任务。thin 认领返回私有尝试令牌和受租约隔离保护的凭据，支持可选的指定 Codex 模型，并使用有上限的 thin 租约时长。`tw task claim` CLI 命令认领指定任务；`tw task release` 仅适用于 legacy 认领，thin 尝试使用带凭据校验的 Worker 释放 API。

## Worker 识别

项目 Workers 标签页使用专属图标标识，代理技能文档补充了 thin 任务的定向认领流程。

## Node 运行时安全

将 Node 运行时更新到 24.22.3，包含 CVE-2026-126051、CVE-2026-123863、CVE-2026-123864、CVE-2026-123865、CVE-2026-123866、CVE-2026-123872 和 CVE-2026-123874 的安全修复。发布前的新候选镜像扫描在已交付的 Node 24.22.2 运行时中检出这 7 个高危漏洞，首个 0.3.25 候选被撤回并在任何产物发布前完成修复。应用镜像从摘要固定的官方 Node 镜像复制经过验证的运行时和头文件，同时保留已评审的 Alpine 软件包基线。源码校验和、原始 Node 许可文本与对应源码通知包一并更新。

## 升级与验证

此补丁沿用 0.3.24 的数据库迁移集合。升级前备份数据库和附件，并遵循[升级指南](../ce-upgrades.md)。

验证涵盖鉴权 PostgreSQL、thin 任务的定向认领与过期写入竞争覆盖，以及私有 GitHub 验收和版本集成。
