# Task Weaver 0.3.6

Changes from 0.3.5. Package and runtime versions are promoted together to `0.3.6`.

## Supervised Chat and live platform access

Chat can query authorized live projects, requirements, tasks, documents and run
history instead of relying only on a page snapshot. Page context follows the
selected resource. Typed operations support bounded multi-step workflows and
request deduplication. Account settings support disabled operations, asking before
execution and automatic operations; resource permissions still apply to every
read and write. Project task execution remains independently controlled.

Memory, skill, MCP, personal task and schedule tools support authorized loading
and maintenance. Repository and member management remain human workflows.
Partners runner integration is deferred; creating an execution slice records
platform work and does not start a sandbox.

## Streaming and model configuration

Authenticated SSE streams readable replies and tool progress. The gateway handles
repeated streaming tool metadata without corrupting tool names, and preserves
structured MCP results while filtering credentials and binary content.

Personal models support confirmed local endpoints, optional API keys and
keyless Ollama. Each model can inherit deployment proxy settings, connect directly
or use a custom proxy. Credentials remain encrypted and account-isolated.
Connection tests accept bounded thinking responses from compatible providers.

## Browsing and interface improvements

Archived projects remain visible in authorized inventory and support read-only
content browsing. Archiving a project preserves authorized Chat completion and
history access without reopening mutations or execution. Current memberships,
credential ceilings and revocations remain enforced.

Migrated private repositories with verified human ownership remain visible even
when their creator attribution uses a legacy API Key identifier. Unowned legacy
catalogs and other accounts' private repositories remain hidden.

Key details show permissions as grouped checkboxes. Model selects and notifications
use theme colors; notification text is selectable and close controls work with
open dialogs. Chat scrolling and bounded draft height keep the composer available.

## Upgrade and recovery

Back up PostgreSQL, skill storage and the credential encryption key ring before
upgrading. Migration `0067` adds per-model proxy configuration. No deployment model
Secret is imported into personal models. Preserve the encryption key ring when
upgrading; restore the verified database and skill snapshot together with the
recorded previous image digests for recovery.
