# Task Weaver 0.3.11

## MCP 规划与上下文协作

新增 14 个工具，覆盖技能检索、技能包安全文本读取、执行切片、计划原子提交和任务／需求
聚合上下文。总计 43 个工具，其中只读模式可见 23 个；HTTP 与 stdio 共用契约和授权执行器。

计划支持无写入预览和持久化 UUID 去重 key，按凭据与项目隔离：相同计划重试返回已有
结果，不同内容冲突。拒绝嵌套越权字段和跨项目引用。切片更新检查精确 `updatedAt` 并遵守
需求租约。聚合读取明确标记截断、续读方式和非快照一致性，不递归展开文档或读取任意路径。

## 升级

先备份数据库与对象存储，执行 `0071_mcp_plan_receipts` 迁移，再启动新 API；本地 `tw`
同步升级后使用新增 stdio 工具。活动凭据的去重记录须保留；轮换密钥会改变去重范围。
临时回退 0.3.10 时可保留新增表。原有 29 个协作工具保持兼容。

工具名称、权限、大小限制和重试语义见 [MCP 使用指南](../mcp-server.zh-CN.md)。
