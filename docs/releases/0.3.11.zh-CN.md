# Task Weaver 0.3.11

## MCP 规划与上下文协作

新增 14 个工具，覆盖技能检索、技能包安全文本读取、执行切片、计划原子提交和任务／需求
聚合上下文。最多 44 个工具，其中 24 个只读，实际清单按当前授权过滤；HTTP 与 stdio 共用契约和授权执行器。

计划支持无写入预览和持久化 UUID 去重 key，按凭据与项目隔离：相同计划重试返回已有
结果，不同内容冲突。拒绝嵌套越权字段和跨项目引用。切片更新检查精确 `updatedAt` 并遵守
需求租约。聚合读取明确标记截断、续读方式和非快照一致性，不递归展开文档或读取任意路径。

## 升级

先备份数据库与对象存储，依次执行 `0071_mcp_plan_receipts`、`0072_api_key_project_creations`、`0073_mcp_security` 迁移，再启动新 API；本地 `tw`
同步升级后使用新增 stdio 工具。活动凭据的去重记录须保留；轮换密钥会改变去重范围。
临时回退 0.3.10 时可保留新增表。原有 29 个协作工具保持兼容。

工具名称、权限、大小限制和重试语义见 [MCP 使用指南](../mcp-server.zh-CN.md)。

## MCP 授权与项目访问

新增 global.project.discover，仅提供有限项目目录元数据。人类主体绑定的创建 Key
在项目创建事务中仅获得该新项目读写权限。外部发现要求实时 invoke 授权和服务器可用状态；
HTTP/stdio 按授权、scope 和只读策略过滤并在每次调用时重新鉴权。新增脱敏 scope 审计、
可信工具只读/项目参数声明及绑定精确操作的单次审批。未配置策略的已有调用默认 allow，
仍受原有权限检查约束。

API 与 CLI 应同时升级。旧 stdio 客户端可能显示静态清单，但服务器调用鉴权仍生效。
新版 CLI 缺少 catalog 接口时拒绝列出工具。临时回退可保留新增表与列，但旧 API
不执行这些新策略；如果需要持续执行这些限制，回退期间须关闭 MCP 访问并恢复已记录的
应用及配置。数据回退应停止写入并恢复完整升级前备份，不要单独删除授权来源或策略记录。
