# Task Weaver 0.3.21

[English](0.3.21.md).

## 交付审阅与工作流可见性

交付面板现在按工作流阶段组织内容，将审阅结论与相关反馈和差异引用放在一起，并允许仅依据引用的反馈提交结论。用户可以直接选择需求交付输入，审阅界面会标明必需交付项，同时保留恢复操作。

## 执行器依赖上下文

任务执行器通过共享 CLI 辅助程序获取依赖上下文，使执行需求工作所需的依赖信息在运行时可用。

## 升级与验证

本版本新增 `delivery_git_baseline` 数据库迁移。请备份保留的数据，并遵循[升级指南](../ce-upgrades.md)。此前公开的版本、标签和签名保持不可变。

验证包括 main 发布门禁、工作流 PostgreSQL 覆盖、依赖上下文 CLI 检查，以及经审阅的双架构候选与消费验证。生产浏览器验收仍需单独进行。
