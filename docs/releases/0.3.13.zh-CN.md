# Task Weaver 0.3.13

[English](0.3.13.md).

## 运行中规划变更

Web、CLI、REST 和 MCP 的规划变更由 core 统一评估，覆盖描述、验收条件、依赖、slice、归属、仓库范围和执行输入。使旧执行失效的变更会立即撤销其授权。持久化控制事件区分通知、停止中、已停止及恢复状态，支持 SSE 补漏与心跳、轮询兜底，不停止无关任务或整个 daemon。

## 有界恢复与 Git 同步

健康节点优先复用原工作区，并在停止、评估和接续期间续租。等待依赖时释放 worker 容量。节点亲和仅为偏好；超过可配置等待阈值后，允许安全重试的任务在预算内跨节点从持久输入和远端代码重新执行，可能丢失本地进度并重复计算。不可重复的外部操作和不可替代的本地输入需要明确恢复处理。旧节点返回后先协调执行权，保留旧成果，不能覆盖新执行。

agent 开工前和交付前必须同步最新目标分支。daemon 提供带认证并校验授权的 Git 能力；agent 负责 merge/rebase、冲突处理与验证。fetch 不会自动更新现有 worktree，失效现场须检查来源后再使用。同步失败应阻塞，不默认 force push，不引入交接提交协议。自动提交包含 DCO signoff；Linux 通过 procfs 识别进程，兼容精简容器环境。已经发出的 Git 或外部请求可能结果不确定，不保证物理执行恰好一次。

## 依赖安全维护

为通过发布安全门禁，升级 Next.js、DOMPurify、body-parser、GraphQL tools，并将共享 schema 和完整依赖图迁移到 Zod 4.6.6。部分更新接口继续保留未提交字段，创建默认值和工具输入 JSON Schema 已针对新版本适配。直接组合或检查导出 schema 的包使用方须采用兼容 Zod 4 的 API；校验错误消息和 issue code 遵循 Zod 4。JSON 资源结构继续作为传输契约。

## 升级与验收边界

启动前应用迁移 `0078_execution_controls`。升级前备份数据库、本地数据及配置和 Secret；回退需要协调恢复，不能只更换旧镜像。参见[恢复规范](../live-planning-recovery.md)和[升级指南](../ce-upgrades.md)。

已验收数据库与 daemon 故障场景、两个物理节点的真实断网及旧节点回归，以及真实 Codex 在规划和远端分支变更后检查旧现场、解决冲突、运行测试并交付签名提交。真实模型的 Git 验收使用临时本地 bare 仓库，不代表所有外部 Git 平台或模型提供方均已认证。
