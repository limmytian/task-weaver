# Task Weaver 0.3.17

[简体中文](0.3.17.zh-CN.md).

## CLI distribution and first use

The CLI release includes an executable `tw` package and its five shared packages.
Release tarballs contain compiled runtime files with publishable dependency
versions and exclude tests, source maps and local logs. The npm workflow verifies
package identity, checksums, immutable versions and stable/prerelease dist-tags
before publishing through a protected environment with provenance.

The source distribution includes documented browser, scoped CLI, agent execution,
review and upgrade paths. Operator-driven smoke checks and autonomous execution
are recorded separately in acceptance evidence.

## Review and documentation

Task review brings goals, outcomes, checks, evidence origins and remaining work
into the existing review flow. Public guides use shared version metadata and
separate general product guidance from environment-specific planning.

## Image tags and security

Main and formal release workflows assign each application's version tag and
`latest` to the same scanned and signed digest. A shared concurrency group
serializes publishing jobs, conflicting version tags stop publication, and all
four resulting references are checked. API/Web tag writes are not atomic;
partial failures require retry with the original version and digests. Older
reruns can move `latest` backward and require operator review.

Update `@hono/node-server` to 2.1.3. BusyBox raw control-character regression
checks cover the rebuilt binary candidate, but image scanners still report
Medium `CVE-2025-60876` package-version matches. These findings are retained;
the release does not claim vulnerability elimination. Scanner results depend on
the advisory database and the exact image being inspected.

## Upgrade

No database migrations are added beyond 0.3.16. Back up retained data and follow
the [upgrade guide](../ce-upgrades.md). Previous public artifacts remain immutable.
