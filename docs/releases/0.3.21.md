# Task Weaver 0.3.21

[简体中文](0.3.21.zh-CN.md).

## Delivery review and workflow visibility

Delivery panels now organize their content by workflow stage, keep review decisions
with the relevant feedback and diff references, and allow decisions based on
referenced feedback alone. Requirement delivery inputs can be selected directly,
and the review surface identifies required deliveries while keeping recovery
actions available.

## Executor dependency context

Task executors receive dependency context through a shared CLI helper. This makes
the dependencies needed to continue requirement work available at execution time.

## Upgrade and verification

This release adds the `delivery_git_baseline` database migration. Back up retained
data and follow the [upgrade guide](../ce-upgrades.md). Earlier public versions,
tags and signatures remain immutable.

Validation includes the main release gates, workflow PostgreSQL coverage,
dependency-context CLI checks, and the reviewed two-platform candidate and
consumption checks. Production browser acceptance remains separate.
