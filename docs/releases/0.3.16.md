# Task Weaver 0.3.16

[简体中文](0.3.16.zh-CN.md).

## Dependency and rendering security

Update vulnerable production and development dependencies, including Hono,
Mermaid, KaTeX, IP-address parsing and URI parsing. Mermaid previews use strict
security settings and an additional DOMPurify pass. Normal diagram labels and
mathematical expressions remain supported; embedded media and script links are
removed. Builds retain the MIT-licensed shadcn styles as source without installing
the optional component generator and its dependency tree.

The pinned Alpine runtime installs musl and musl-utils `1.2.5-r24`. The current
BusyBox `CVE-2025-60876` findings remain: the configured Alpine repository does
not provide a fixed package. These findings are recorded rather than suppressed.
Vulnerability results depend on the advisory database used during verification.

## Public artifact privacy

Source archives, staged npm packages and final release directories reject local
configuration, private keys, database backups, operator home paths, symlinks and
recognized credential formats. Compiled package files are included in the check.
Failures report locations and categories without printing matched values.
Scanner reports redact host home paths, and source-control and Docker exclusions
cover operator credential directories and backups.

These checks complement artifact review; they do not identify every private
hostname or arbitrary sensitive document. Existing published versions remain
immutable.

## Upgrade

No database migrations or data rewrites are added beyond 0.3.15. Follow the
standard candidate verification and immutable release workflow before deployment.
