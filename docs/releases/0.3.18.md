# Task Weaver 0.3.18

[简体中文](0.3.18.zh-CN.md).

## Node runtime security

Update the Node runtime and build verification baseline to 24.22.2, which
includes the 24.22.1 security fixes for CVE-2026-111497, CVE-2026-105482,
CVE-2026-106069 and CVE-2026-105483. The application images copy the verified
runtime and headers from the digest-pinned official Node image while retaining
the reviewed Alpine package baseline. Source checksums, original Node license
texts and the corresponding-source notice bundle are updated together.

The tagged 0.3.17 source candidate was withheld from binary publication after
fresh image scans detected the vulnerable Node 24.21.0 runtime. Its public Git
tag remains immutable. This patch carries the CLI distribution, review evidence
and verified version/latest image tagging described in the
[0.3.17 preparation notes](0.3.17.md).

## Release and upgrade

Both application architectures must pass the runtime, source, deployment and
vulnerability gates before publication. BusyBox CVE-2025-60876 package-version
matches remain disclosed and are separate from the Node fixes. Do not interpret
successful raw-control-character regression checks as vulnerability elimination.

No database migrations are added beyond 0.3.16. Back up retained data and follow
the [upgrade guide](../ce-upgrades.md). Published versions and tags are immutable.
