# Task Weaver 0.3.20

[English](0.3.20.md).

人工 PR 同步增加显式确认已检查新头提交的能力：`tw req repo sync-pr --expected-head`。服务端重新读取可信代码托管平台，保留 PR、分支、版本、时间戳、权限和租约校验；仅允许工作流尚未推进且无活动或已批准审阅的交付记录更新。外部合并事实不会自动产生验收结论，旧头与新头均写入审计。

修复已重现的 Docker 预检查超时：原 1.5 秒时限可能在 MCP 初始化开始前终止检查，随后被包装成初始化失败。引擎能力与镜像卷检查分别采用有上限的五秒时限，仅查询必要能力；保留内部失败原因，公开错误仍脱敏。不增加隐式重试，不放宽 Linux、内存、CPU、进程、只读卷、取消或清理限制。

相较 0.3.19 没有新增数据库迁移。旧公开标签、镜像、包和签名均保持不可变。BusyBox CVE-2025-60876 的包版本扫描发现继续披露，现有已审阅二进制替换和 wget 控制字符检查保持有效；这些检查不等于完整消除漏洞或发行版认可，不增加扫描忽略规则。

验证覆盖真实 PostgreSQL 下的头提交同步及授权、确定性的慢速与无响应 Docker 检查，以及现有完整隔离 MCP 测试。生产登录态浏览器验收仍单独保留。
