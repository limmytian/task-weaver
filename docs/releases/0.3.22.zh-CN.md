# Task Weaver 0.3.22

[English](0.3.22.md).

## 任务 Worker 与事件

限定范围的 Worker 通过带隔离令牌的租约领取单个任务，使用隔离工作区并生成可追踪的结果。持久事件支持授权消费和 Worker 唤醒。旧 daemon 和 slice 调度入口已移除，历史记录保留。

## 升级与验证

本版本新增数据库迁移 0085–0104。请备份数据库和对象数据，遵循[升级指南](../ce-upgrades.md)，并在升级前审查 Worker 切换和回滚方案。此前公开的版本、标签和签名保持不可变。

合入源码已通过源码和数据库检查。发布制品还须通过独立的原生候选、扫描、签名和消费验证。
