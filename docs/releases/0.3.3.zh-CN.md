# Task Weaver 0.3.3

相较于 [v0.3.2](https://github.com/limmytian/task-weaver/releases/tag/v0.3.2) 的变更。
本文描述已准备的源码；发布产物与部署须分别通过授权和验证，已有镜像不会自动获得这些变更。
[English canonical version](0.3.3.md)。

## 主要变更

- 关闭公开注册的本地账户体系：管理员预置账户、一次性激活与恢复、可撤销浏览器会话，以及稳定的人类和受管理 Agent 身份。
- 绑定主体、限定作用域的 API Key，支持轮换、显式到期时间或显式选择无时间到期，并检查实时撤销与凭据祖先关系。
- REST、tRPC、GraphQL、SSR、SSE 共享认证。项目角色、个人归属和检索权限覆盖正文、嵌套关联、历史、文件、图谱、MCP、仓库元数据、Webhook 与执行记录。
- Daemon 监督进程和已分配的项目 Ti 执行需要显式阶段权限；子进程凭据隔离，任务能力最多 15 分钟且不得超出父凭据或当前租约。保留既有评审身份与 fence 规则。
- 账户、成员、Agent 和 Key 管理界面，会话与缓存隔离，以及 CLI login/logout/whoami。
- 已接受的 Open weave 品牌及靛紫/蓝配色，包含可访问的明暗主题、标志母版、favicon、Web/登录/CLI 和仓库素材。
- 依赖安全更新（包含 Next.js 16.3.8），以及认证、跨身份、执行与升级回归验证。

## 兼容性影响与升级要求

此次补丁有意替换旧信任模型。依赖匿名业务访问、自声明 actor 请求头、旧未绑定 Key 或管理员隐式访问的集成必须调整。
Actor 请求头、client/node ID 和旧标签均不授予权限。实例管理员不会自动获得项目成员资格或其他人的个人数据访问权。
项目可见性不包含执行、评审、合并或 MCP 调用权限。人类 Key 创建的个人内容归人类所有，Agent 执行单独归因。

REST/tRPC/GraphQL 调用需要已验证凭据；浏览器变更还需精确 Origin 和签名 CSRF。
API Key 不能作为浏览器会话。缺失、过期、撤销凭据均拒绝访问，没有恢复旧访问模式的开关。
参见[认证访问](../authenticated-access.md)和[认证配置](../authentication-contract.md)。

迁移日志从截至 `0047_ti_agent_overhaul` 的 48 项推进至截至 `0058_auth_migration_receipts` 的 59 项。
仅迁移 schema 不会建立可信归属或成员关系。升级实例开放前应完成：

1. 在脱敏副本上演练。停止 API/Web 写入与所有 runner，验证包含扩展定义的完整数据库备份及匹配的技能存储，保留旧代码/镜像/配置引用，记录 UTC 截止时间。
2. 执行前向迁移。API/Web 使用相同数据库、`TW_AUTH_SECRET`、`TW_AUTH_BASE_URL` 和精确 `TW_AUTH_TRUSTED_ORIGINS`；非 loopback 使用 HTTPS 与统一浏览器源/反向代理。通过部署 Secret 显式注入；宿主机 `.env` 不会自动向现有 Compose/Kubernetes 模板注入任意认证变量。
3. 使用一次性部署 `TW_AUTH_BOOTSTRAP_SECRET` 初始化首个人类管理员，随后移除该配置。预置并激活其他人类和受管理 Agent。没有公开注册，也不会从旧标签推断身份。
4. 使用离线归属工具按固定截止时间生成清单，审核资源至 actor 的显式映射和项目成员关系，dry-run 后以当前指纹和维护确认执行。通过 Secret 设施提供 `TW_AUTH_MIGRATION_DATABASE_URL`。
5. 重新签发有限范围凭据。切换会撤销旧 Key、清理认领、隔离旧 delegation/run、暂停 daemon，并使 provider/仓库/embedding readiness 失效。重新核验集成并显式重新注册已认证客户端；后续获授权的执行必须使用新租约和 fence。
6. 开放写入前验证跨用户/项目/个人隔离、登录、凭据过期/撤销和存储。未映射的非项目旧数据继续隔离；历史审计归因保留。

具体命令、manifest 和恢复语义见[离线升级与恢复](../authenticated-access.md#offline-upgrade-and-recovery)。
不得从共享旧 Key、邮箱、标签或 UUID 字符串猜测归属。

## 限制与恢复边界

SLO、assistant/plans 入口、到期/后台获取、尚未转换的 embedding 和 assistant/Partners 出站 workers、跨身份本地 MCP 节点共享，以及个人自主 Ti 保持关闭。
保存 schedule/policy 或连接已授权事件流不会启动 worker。
公开注册、OIDC/企业 SSO、MFA、SaaS 多租户和自定义策略引擎不在本版本范围内。

过期或撤销的执行不得沿用旧 run ID、token 或 fence 恢复。协调恢复需要当前授权；脏改动保留，冲突或丢失的工作区进入隔离与评审。
迁移或注册不意味着自动重启 runner。

切换后优先前向修复。完整回退需要停止新写入，恢复升级前完整数据库及匹配的存储、代码和配置；备份后的写入会丢失。
不得让 0.3.2 二进制连接已变更的 0.3.3 实时数据库。仅 schema dump 或切换镜像不足以恢复。
参见[升级与恢复](../ce-upgrades.md)。
