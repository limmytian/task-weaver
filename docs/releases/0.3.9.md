# Task Weaver 0.3.9

## Human direct integration completion

Fix the 0.3.8 gap where a human directly integrated a delivered branch without a PR,
but a historical requirement could not complete because no repository delivery
record could be reconciled. Web, REST and CLI now accept a full delivered commit
and verify that the configured target branch contains it through a trusted server
forge connection. The operation records direct integration evidence, preserves
review decisions and configured workflow stages, and retains existing permissions,
lease, concurrency, idempotency and audit protections. Explicit PR workflows still
require PR evidence.

No database migration is required beyond 0.3.8. The fix needs no fabricated PR,
repository unlink or database repair. See [human delivery reconciliation](../manual-pr-reconciliation.md).
