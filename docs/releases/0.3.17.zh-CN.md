# Task Weaver 0.3.17

[English](0.3.17.md).

## CLI 分发与首次使用

CLI 发布物包含可执行的 `tw` 包及其五个共享依赖包。发布 tarball 包含编译后的运行时文件，使用可发布的依赖版本，排除测试、源码映射及本地日志。npm 工作流在受保护环境中执行带来源证明的发布，并事先核对包身份、校验和、不可变版本及稳定版／预发布版的 dist-tag。

源码分发提供浏览器、受限 CLI、自主 Agent 执行、结果审阅及升级路径说明。验收证据分别记录操作员驱动的 smoke 检查和自主执行。

## 审阅与文档

任务审阅在现有流程中呈现目标、结果、检查、证据来源和剩余工作。公开指南使用共享版本元数据，并将通用产品指南与环境相关计划分开。

## 镜像标签与安全

main 与正式发布工作流将每个应用的版本标签和 `latest` 指向同一个经过扫描、签名的摘要。共享并发组串行执行发布任务；版本标签冲突时停止发布，并核对最终四个引用。API/Web 标签写入不是原子操作；中途失败需使用原版本及摘要重试。重跑旧工作流可能使 `latest` 回退，需要操作员审阅。

将 `@hono/node-server` 更新至 2.1.3。重建二进制候选已通过 BusyBox 原始控制字符回归，但镜像扫描仍报告 Medium `CVE-2025-60876` 包版本匹配。这些发现予以保留，不宣称漏洞清零。扫描结果取决于所用漏洞数据库和实际镜像。

## 升级

相比 0.3.16 未增加数据库迁移。请备份保留数据并遵循[升级指南](../ce-upgrades.md)。历史公开发布物保持不可变。
