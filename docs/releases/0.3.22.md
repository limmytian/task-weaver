# Task Weaver 0.3.22

[简体中文](0.3.22.zh-CN.md).

## Task workers and events

Scoped workers acquire individual tasks with fenced leases, isolated workspaces and traceable results. Durable events support authorized consumption and worker wakeups. The legacy daemon and slice scheduling entry points have been removed; historical records remain available.

## Upgrade and verification

This release adds database migrations 0085–0104. Back up retained database and object data and follow the [upgrade guide](../ce-upgrades.md). Review worker cutover and rollback before upgrading. Previously published versions, tags and signatures remain immutable.

Source and database checks passed on the merged source. Release artifacts require the separate native candidate, scanning, signing and consumption gates.
