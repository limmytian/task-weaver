# Task Weaver 0.3.7

Changes from 0.3.6. Package and runtime versions are promoted together to `0.3.7`.

## Model invocation accounting

Ti Chat, its tool loops and model-backed platform operations record actual model
invocations once, alongside existing daemon and Ti execution accounting. Immutable,
secret-free model configuration snapshots preserve attribution after models are
edited or deleted. Complete, partial and unknown usage remain distinct; missing
tokens and costs are not invented. Personal and project visibility remains scoped
to current permissions.

## Attachment documents

Attachment documents complement Markdown with original-file upload, download,
preview, associations and immutable file history. PostgreSQL stores metadata;
original bytes live in persistent local storage shared by API and Web services.
Web, REST and CLI operations enforce the same permissions and concurrency checks.
Metadata edits create document history without duplicating file bytes.

Search covers titles, descriptions and tags. File-content extraction, full-text or
vector indexing of file contents, OCR and online Office editing are not included.
PNG and supported images render directly; PDFs render through a local PDF.js canvas;
plain text renders escaped with a 1 MiB preview limit. Other types remain downloadable.
Document creation no longer fails from duplicate CodeMirror state dependencies,
and requirement associations are displayed in the document sidebar.

## Upgrade and recovery

Back up PostgreSQL, skill storage, attachment storage and the credential encryption
key ring before upgrading. Migrations `0068` and `0069` add invocation accounting,
configuration snapshots and attachment metadata/history. Configure
`TW_ATTACHMENT_STORAGE_DIR` as a persistent directory accessible to both API and
Web services; preserve it with database snapshots. `TW_ATTACHMENT_MAX_BYTES`
controls the upload limit (default 50 MiB). Preserve existing Secrets and the
encryption key ring. Restore matching database and file-storage snapshots together
with recorded previous image digests for recovery.
