# Task Weaver 0.3.15

[English](0.3.15.md).

## 人工审阅的计划暂存

AI 生成的计划在应用前以服务端草稿形式持久化暂存。草稿保留修订版本与已验证的实时依赖图指纹，支持重载恢复；应用时在同一事务内重新校验权限、版本、合并后的依赖图与执行租约，实现原子提交。并发编辑与双击提交只产生一份计划和幂等回执，应用失败不留半份计划。暂存条目与依赖编辑按合并后的依赖图校验，支持新增边与既有边混合；重复或成环的暂存依赖会被拒绝并给出可操作的诊断信息。计划切片泳道显示任务指派，暂存指派可编辑，计划编辑器在窄屏下保持可用。新需求保持 `draft`；暂存绝不启动调度，需求入口将 Assistant 交接连接到显式的应用确认。

## 交付物证据审阅

交付物现在可以按确切来源审阅。工作流输出绑定到签名节点与不可变文件版本；读取采用经过认证、有界的节点读取协议，具备过期、防重放、取消和每节点并发上限。路径仅来自注册的输出清单，读取过程针对路径穿越、软链接与替换竞态做围栏防护，并进行完整文件指纹校验和读取结果记录。

有界预览覆盖文本与 Markdown、CSV/TSV 表格、图片、受支持的音视频及 PDF，JavaScript 与 TypeScript diff 支持语法高亮。采样与截断都有明确标识，下载原始字节是独立的显式认证操作；HTML/SVG 等主动内容仍仅支持下载。Git 比对将 base 和 head 固定到不可变提交，目录树与分页不随分支移动。已验证证据可提升为常规附件并绑定不可变文件版本；重复提升不会产生重复附件，失败提升会自动清理。执行节点离线后仍可读取已提升附件，权限撤销或指纹损坏无法通过回退绕过。证据生产者上报可用性，受信 forge 响应在流式传输中保持有界，守护进程执行过程中校验证据读取。

## 安全与传输加固

新增的证据与 worker 控制台 Web 入口在资源校验之前完成认证，并纳入一次性 PostgreSQL 传输套件验证。已认证的证据响应不可缓存，不支持的文本编码被拒绝，制品根目录防路径穿越，被中断或拒绝的证据提升不会遗留已验证预览。
