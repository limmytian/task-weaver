# Task Weaver 0.3.5

基于 0.3.4，统一升级软件包和运行时版本到 `0.3.5`。[English](0.3.5.md)。

## 个人 Chat 配置

用户可配置和编辑自己的 Provider、Model、公网 HTTPS Base URL 和 API Key，选择
默认模型、测试连接、替换和删除密钥。密钥按账号隔离并用 AES-256-GCM 加密，接口
只显示固定掩码。Credentials 可编辑；有已保存密钥时 `unknown` 不阻止聊天。

Chat 不再读取环境密钥引用或回退 Provider。旧模型信息保留，但用户需要重新填写
密钥；不会自动导入部署 Secret。Web 和 API 需要相同的部署加密密钥环，详见
[个人 Chat 密钥说明](../personal-chat-credentials.md)。丢失密钥环会导致无法解密。

地址只支持公网 HTTPS 443；拒绝私有地址和重定向，将验证后的 DNS 地址固定到请求。
此入口不支持私有模型网关。

## 授权、设置和体验

REST/tRPC Chat 接入账号和资源授权，修复模型调用前的权限拒绝。会话历史按账号
隔离，上下文和修改操作检查当前权限。Chat 顶部提供作用于当前账号所有聊天的设置：
手动确认、仅预览、自动执行勾选操作。带说明的勾选项替换逗号列表，高级设置包括每日
次数、超时、重试及不确定操作转审核。任务策略仍在 Agents，两组设置不会互相覆盖。

结构化提案及内置工作流支持创建/修改任务、创建/暂停日程、添加评论/笔记和创建待审核
文档。Ti 入队仍检查独立执行权限和任务策略；Chat 不会打开关闭的执行器。本补丁不
提供通用的模型自主工具调用循环。

自己发的消息靠右，回复靠左。Enter 发送，Shift+Enter 换行；组合输入保护防误发，
失败保留草稿，窄屏设置弹窗保留聊天和草稿。

## 升级和恢复

迁移 `0063` 修复旧 Ti 动作约束；旧 Pi 入队的已批准提案需重新确认，已完成历史保留。
迁移 `0062` 增加可空加密字段，不导入旧密钥或改变模型信息。升级前备份数据库、技能
数据和密钥环。恢复使用升级前已验证的数据库/技能快照与旧镜像摘要，不要假设旧版本
可直接运行在升级后的数据库上。

删除品牌候选、旧 mockup 和重复历史规划；保留正式素材、规范、模板和字体许可证。
