# Task Weaver 0.3.5

Changes from 0.3.4. Package and runtime versions are promoted together to `0.3.5`.
[简体中文](0.3.5.zh-CN.md).

## Personal Chat models and credentials

Users can create and edit their own provider, model, public HTTPS Base URL and API
key, select a default Chat model, test connections, replace and delete keys. Keys
are account-isolated and AES-256-GCM encrypted; responses show only a fixed mask.
Credential status remains editable. `unknown` permits Chat with a saved key.

Chat no longer resolves provider keys from environment references or fallback
providers. Existing model metadata is preserved, but users must re-enter keys.
Deployment Secrets are never automatically imported. Configure the same encryption
key ring for Web and API before saving personal keys; see
[Personal Chat credentials](../personal-chat-credentials.md) for setup, backup,
rotation and recovery. Losing the key ring makes stored credentials unreadable.

Custom endpoints require public HTTPS on port 443. Private addresses and redirects
are rejected; validated DNS addresses are pinned to requests. Private model
gateways are not supported by this self-service configuration interface.

## Chat authorization and settings

Owner-scoped REST/tRPC authorization fixes the pre-model permission denial.
Conversations and history are account-isolated; context and actions require current
resource permissions. Chat settings apply across the current account's chats:
manual confirmation, preview only, or automatic execution of selected actions.
Described checkboxes replace comma-separated permissions. Advanced settings include
daily limits, timeouts, retries and uncertain-action review. Task execution policy
stays on Agents; neither policy overwrites the other.

Structured proposals and built-in workflows can create/update tasks, create/pause
schedules, add comments/notes and draft reviewed documents. Ti run queueing retains
independent execution entitlements and task policy; Chat never activates a closed
executor. This patch does not add a general model-selected tool-call loop.

Outgoing messages appear on the right and replies on the left. Enter sends,
Shift+Enter inserts a line break, composition guards protect IME input, and failed
sends retain drafts. Settings preserve Chat and drafts on narrow screens.

## Upgrade and recovery

Migration `0063` corrects the legacy Ti action-type constraint. Old approved Pi
queue proposals require fresh confirmation; completed history remains intact.
Migration `0062` adds nullable encrypted credential columns without importing old
keys or changing existing model metadata. Back up PostgreSQL, skill data and the
key ring before upgrading. Recover with the verified pre-upgrade database/skill
snapshot and recorded previous image digests; do not assume old binaries can
safely run against the upgraded database.

Obsolete brand candidates, product mockups and duplicate historical plans were
removed. Approved artwork, tokens, templates and font licenses remain.
