# Task Weaver 0.3.14

[English](0.3.14.md).

## 看板与界面有界渲染

看板各列现支持独立加载与过滤后的任务总数统计。看板读取与渲染采用显式分页，避免中大型项目下的 DOM 堆积与响应卡顿。项目概览和任务详情按需加载。需求工作区读取与大文档预览实施有界截断，Markdown 解析避免重复计算并保留编辑器历史。

## 数据库与连接池优化

显式约束数据库连接池配置，优化索引权衡。在获取事务连接前先完成被指派人凭证解析，降低连接占用时长。项目健康度指标聚合无需将全部任务装载至内存。

## 易失性 Worker 控制台

新增按需易失性 worker 控制台，提供实时执行日志与运行状态观察。在执行权限撤销（abort）时立即清理控制台缓冲区，避免残留陈旧输出。合并整合多个活跃 worker 的控制台元数据轮询。

## 作用域 Worker 能力执行

Worker 在自身权限范围内进行能力发现与引导加载。受托能力经由实时 worker broker 校验，Worker 能力执行及审核后记忆创建均受到严格门禁控制。

## 变更审计原因保留

任务和需求更新在 Web、REST 及 CLI 全渠道均完整保留显式审计原因（audit reason），保障变更全生命周期可追溯。

## 升级与验收

0.3.14 未引入新的数据库迁移。若从 0.3.12 或更早版本升级，请先执行 `0078_execution_controls`。升级前请做好数据备份。
