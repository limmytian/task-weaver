# Task Weaver 0.3.14

[简体中文](0.3.14.zh-CN.md).

## Bounded board and kanban performance

Kanban board columns now load independently with filtered task totals. Board reads
and rendering are bounded with explicit task pages, preventing latency spikes on
large projects. Project views and task details are deferred until requested.
Requirement workspace reads and document previews are bounded, and Markdown
rendering avoids redundant work while preserving editor history.

## Database and connection pooling

Database connection pool configuration is explicitly bounded, and index tradeoffs
have been validated. Assignee credentials resolve before transaction connections
are reserved, reducing lock duration. Project health metrics aggregate without
materializing every task in memory.

## Volatile worker console observation

A volatile on-demand worker console provides real-time worker execution logs
and console observation. Worker console buffers are cleared immediately on
execution authority abort to prevent stale output retention. Console metadata
polling across active workers is consolidated.

## Scoped worker capability execution

Workers discover and bootstrap scoped capabilities under worker authority.
Delegated capabilities are verified through the live worker broker. Execution
of worker capabilities and reviewed memory creation are strictly gated.

## Update audit reasons

Task and requirement updates now preserve explicit audit reasons across Web,
REST, and CLI interfaces for full traceability.

## Upgrade and verification

No new database schema migrations are introduced in 0.3.14. Apply preceding
migration `0078_execution_controls` if upgrading from 0.3.12 or earlier.
Back up PostgreSQL and local workspace data before upgrading.
