# Task Weaver 0.3.4 — 已准备的源码

相对 0.3.3 的变更。本说明对应 `0.3.4` 开发分支；发布产物、版本提升和部署仍是独立步骤。
[English](0.3.4.md)。

## 账户与凭据体验

- 登录采用实例默认会话时长；邀请与恢复提供明确的次级入口。仅在确认实例尚未初始化时显示首次设置。
- 账户菜单统一提供账户设置与退出。敏感操作在当前流程中确认身份，取消不会执行原操作。
- Managed Agents 默认只显示活跃身份。已停用身份独立搜索和分页，可通过软删除隐藏。停用不可逆；同名 Agent 保持不同 ID，不继承旧身份的权限。
- Agent 详情展示项目访问，并区分角色权限与显式执行权限，提供从创建身份到配置访问、签发 Key 的引导。
- 普通 Key 详情展示具名范围、不可变主体、状态和到期时间，支持授权编辑、前后对照和并发变更检测。保存授权变更会使派生凭据与执行委托失效，后续扩权不会恢复旧授权。原始密钥仍仅在签发时展示。
- 权限选择支持有界搜索、分页、跨页保留、分组/本页/匹配项/全部可选项选择及部分选中状态。每个 Key 仍最多包含 100 个显式 scope；当前选择不涵盖未来新项目。
- Ti 各入口统一使用 Chat 的 Sparkles 图标，Agent Usage 使用分析图标。

## 执行器可用性与恢复

Daemon 的工具配置独立记录资源中断，不与 Agent 身份或运行 token 总量混淆。确认的额度耗尽或限流会阻止受影响工具获取、启动新工作；认证和账单问题需要人工处理。恢复遵守租约隔离，保留工作区改动、终态任务和已完成交付。资源中断不消耗任务、审查或交付的失败重试预算；AI 审查中断不会生成代码问题或批准工作。

Daemons 页面突出受阻工具、额度窗口、重置时间和恢复操作，技术详情与恢复历史按需展开。刷新为在线 daemon 排队查询，并保留现有阻断。授权重试记录原因，在后续查询或运行确认前仍显示未验证。

Codex 已接入有界、只读的主动额度查询。其他工具在此版本尚未接入经过验证的自动查询。Antigravity 用户可通过交互界面的 `/usage` 或 `/quota` 查看额度，该能力尚未接入 Task Weaver。缺失、过期和不支持的计数显示为未知。自动跨工具回退默认关闭，需要显式、有限的项目策略、最新订阅证据及兼容的任务约束；不允许付费 API 回退。详见[执行器可用性说明（英文）](../executor-availability.md)。

## 兼容性与升级

相对 0.3.3，迁移日志新增三项：

- `0059_agent_retirement`：不可逆的身份退休元数据。
- `0060_key_grant_version`：Key 授权编辑的乐观并发控制。
- `0061_executor_availability`：工具观察、历史记录和可空的项目回退策略。

将新源码用于已有数据库前，需要应用完整迁移日志，并按[升级指南（英文）](../ce-upgrades.md)备份、演练。现有公开标签和产物不变。旧 daemon 不报告可用性；参与执行的工作节点需要升级，才能执行资源阻断。主体绑定认证、项目权限、凭据上限、近期身份确认与租约隔离继续生效。

在明确授权版本提升前，包和运行时版本保持已发布基线。本源码说明不代表已发布新包、镜像、标签或部署。
