# Task Weaver 0.3.10

## Task Weaver MCP Server

外部 MCP 客户端可通过 `tw mcp serve`（本地 stdio）或 API 服务内的
`/api/v1/mcp-server`（Streamable HTTP）使用 29 个协作工具，覆盖项目查询、
需求/任务协作、认领/评论/依赖、Markdown 文档及授权搜索。原有外部 MCP Registry 保持兼容。

两种传输均保留 scoped 身份、密钥实时撤销、归属隔离、工作流/依赖约束和任务/文档
乐观并发校验；只读模式同时隐藏写工具并拒绝执行。请求、结果、并发和超时有明确上限，
取消不能撤销已提交写入。首版使用 API Key；OAuth-only 接入、resources、prompts、
订阅与附件传输不在首版工具范围。

相比 0.3.9 不新增数据库迁移。请成对升级 API/Web 镜像，并为实际 API 域名配置路由与
Host 白名单；HTTP MCP 不由 Web 容器提供。参见 [MCP 使用说明](../mcp-server.zh-CN.md)、
[部署说明](../deployment.md)和[升级恢复说明](../ce-upgrades.md)。
