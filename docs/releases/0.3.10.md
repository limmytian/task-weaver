# Task Weaver 0.3.10

## Task Weaver as an MCP Server

External MCP clients can now use 29 Task Weaver collaboration tools through
`tw mcp serve` (local stdio) or `/api/v1/mcp-server` (Streamable HTTP in the API
service). The catalog covers project retrieval, requirement/task collaboration,
claims/comments/dependencies, Markdown documents and authorized search. Existing
outbound MCP Registry commands remain compatible.

Both transports preserve scoped identity, live key revocation, ownership,
workflow/dependency guards and optimistic task/document updates. Read-only mode
hides and rejects writes. Requests, results, concurrent calls and deadlines are
bounded; cancellation does not undo already committed writes. API-key clients
are supported; OAuth-only onboarding, resources/prompts/subscriptions and
attachment transfer are outside this version's catalog.

No database migration is required beyond 0.3.9. Upgrade the API/Web image pair
and configure the real API route and Host allowlist. HTTP MCP is not served by
the Web container. See [MCP setup](../mcp-server.md),
[deployment](../deployment.md) and [upgrade/recovery](../ce-upgrades.md).
