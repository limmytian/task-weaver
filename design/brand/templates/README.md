# Reusable presentation templates

The selected A geometry and indigo/blue palette are approved. These are prepared, editable presentation assets, not an upload or release.

- `social-light.svg`, `social-dark.svg`: 1280×640 social/GitHub preview canvas.
- `readme-light.svg`, `readme-dark.svg`: 960×240 repository header canvas. Use theme-aware `<picture>` sources when integrated and retain descriptive alt text.
- `screenshot-frame.svg`: 1440×1000 canvas with a 1344×756 placeholder for a sanitized product screenshot. Replace the placeholder and caption before distribution; never treat it as actual product evidence.
- `manifest.json`: file sizes and SHA-256 hashes.
- `index.html`: visual export catalogue.

SVG text stays editable, with embedded Geist SemiBold and its adjacent `FONT-LICENSE.txt`. Keep that license with distributed font-bearing artwork. Verify final raster text rendering in the exporter of choice; no raster social export is approved merely by rendering a differently substituted font. Use the logo mark masters for tiny icons rather than shrinking these canvases.

Copy templates before changing content. Keep safe area, scale and color rules from `../GUIDE.md`. No external artwork or image service was used. Product integration, public uploads and release inclusion are separate actions.
