# Round 2: T/W studies

Open `index.html` for four new editable directions responding to round-one
feedback. D shares a T crossbar and a continuous W; E uses softer W curves;
F combines the initials in a solid compact silhouette; G explores lowercase tw.
No geometry uses an unexplained cut or an over/under weave. All remain candidates.

Each direction includes transparent light/dark color and light/dark single-ink
SVG files (16 total), actual 16/20/24/32 px previews and static navigation,
login and README/social examples. Controls run locally with no product API.

Geometry and preview code are original repository-authored work by Codex under
the repository Apache-2.0 license and existing trademark policy. No external
artwork, image-generation service or paid assets were used. Wordmarks reuse the
unmodified Geist fonts and full SIL OFL 1.1 license in `../fonts/`. No font
outlines or trademark registration/clearance claims are included.

Round one remains available in the parent directory for comparison. Owner
selection, final optical refinements, master exports and official product
installation remain separate downstream work. Release inclusion is undecided.
