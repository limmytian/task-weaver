# Task Weaver logo candidates

The latest exploration is [round 2](round-2/index.html): four continuous T/W
studies responding to owner feedback. The first round below is retained as
history; none of its directions was selected.

Open `index.html` in a browser to compare three unapproved directions: A (open
weave), B (common ground), C (woven W). Choose a candidate and light/dark or
single-ink variants to inspect static navigation, login and README/social examples.
The 16/20/24/32 px strip uses actual CSS pixel sizes. No application data, network
API, remote font, analytics or production integration is used.

The 12 SVG files are editable candidate geometry with transparent backgrounds,
not selected master artwork. Each uses a 64 × 64 viewBox, explicit solid colors,
accessible title/description and local masks where needed. There are no scripts,
external references, embedded raster images, gradients or font glyph outlines in
the SVG marks. The HTML preview has local-only controls.

Geometry and preview code were authored for Task Weaver in this repository by
Codex. No image-generation service, external reference artwork or paid asset was
used. Project-authored geometry/code uses the repository's Apache-2.0 license;
existing trademark policy still applies and no registration or clearance claim
is made. The unmodified Geist Regular/SemiBold WOFF2 files came from the locked
`geist` workspace dependency; its copyright and SIL OFL 1.1 license are preserved
in `fonts/LICENSE.txt`. Candidate wordmarks use live Geist text, not converted
font outlines. Redistribution must retain those font notices.

Colors: light uses indigo `#4f46e5` and teal `#0f766e`; dark uses `#a5b4fc` and
`#5eead4`. Single-ink variants use `#17212b` or `#f5f7fa`. Final token selection,
optical small-size refinements, favicon exports and product installation require
owner selection and the existing downstream tasks. No candidate is the official
identity and this artifact does not decide release inclusion.
