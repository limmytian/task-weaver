# Task Weaver logo artwork

The original A weave is the owner-selected logo geometry. Both strands have equal weight and retain the approved over/under relationships. Colors are provisional pending the brand token task; these exports do not install a product theme.

## Files and usage

`mark-{light,dark,ink,white}.svg` are editable transparent vector masters. `wordmark-*.svg` retain editable text and embed the existing Geist SemiBold font for consistent browser rendering. The existing Geist fonts and SIL Open Font License are in `../e2-candidates/fonts/`; install the font before editing or rendering wordmarks. Do not substitute typography for distributed final artwork without checking its metrics. Raster exports currently cover the standalone mark only.

Transparent PNG marks: 16, 24, 32, 48, 64, 128, 180, 192, 256 and 512 pixels for each variant. `favicon.ico` contains transparent 16/32/48-pixel PNG entries. These are export candidates, not installed browser or app assets. `manifest.json` records asset hashes and sizes.

Keep at least 8 master units of clear space outside visible artwork. Minimum standalone size is 16 pixels; prefer 24 pixels or larger in navigation. Minimum horizontal wordmark width is 150 pixels. Preserve aspect ratio, strand weights and crossing gaps. Do not stretch, rotate, add shadows/gradients, close the crossing gaps or recolor the strands independently of the approved palette. Use ink on light backgrounds and white on dark backgrounds when color is unsuitable.

Geometry is original project artwork, derived from the selected A candidate, with no external image assets. Repository license and TRADEMARKS.md continue to apply. No trademark registration or clearance is claimed. Rendered PNGs use librsvg. Final visual acceptance and color-token approval are tracked in Task Weaver.
