# Governance

Task Weaver is currently a maintainer-led open-source project.

## Maintainer

The project maintainer is [limmytian](https://github.com/limmytian). The
maintainer is responsible for repository administration, releases, security
coordination, contributor access, roadmap stewardship, and final decisions when
community consensus cannot be reached.

## Decision Making

Routine changes are decided through public issue and pull request discussion.
For substantial changes, maintainers consider technical quality, compatibility,
security, maintainability, user impact, and available implementation capacity.

Acceptance of a proposal does not guarantee a delivery date. Decisions and
maintainer roles may evolve as the contributor community grows.

## Contributions and Ownership

Contributors retain copyright in their contributions and submit them under
Apache-2.0 after certifying the Developer Certificate of Origin. Repository
access or a GitHub role does not transfer copyright or create authority to bind
other contributors.

Changes to licensing, governance, or the project identity require explicit
maintainer approval and public documentation.
